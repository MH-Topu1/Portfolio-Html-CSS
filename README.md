# Personal Portfolio Website

A simple and responsive personal portfolio website built using **HTML5** and **CSS3**.  
This portfolio is designed to showcase personal information, skills, projects, and contact details in a clean and professional way.

## Features

- Clean and modern design
- Responsive layout
- About section
- Skills section
- Project showcase
- Contact section
- Simple navigation
- Easy to customize
- Lightweight and fast

## Technologies Used

- HTML5
- CSS3
